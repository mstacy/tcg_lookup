# TCG Lookup

Point a laptop or phone camera at a trading card to identify the game and read the card's title.

## How it works

1. **In-browser detection (OpenCV.js):** finds the card's outline in the live feed, waits until it's held steady, then perspective-corrects the card into a flat 630×880 crop.
2. **Reading (Claude, `claude-opus-5-5`):** the crop is read with structured output: game, title, subtitle, set code, collector number, and a best guess at the set from its symbol. The fixed prompt is prompt-cached.
3. **Retrieval (the RAG step, `lib/catalog/`):** the reading is matched against real catalog cards.
   - Magic: Scryfall finds the exact printing from set code + number, or every printing of the name.
   - Cyberpunk TCG: a snapshot of the whole JustTCG catalog in `data/catalog/`, matched locally.
   - Other JustTCG games: a name search.
4. **Choosing (only when ambiguous):** if several printings fit, Claude sees the photo together with the candidates (and their images, for Magic) and picks one by id. Otherwise the best-ranked candidates stay in the set dropdown.
5. **Pricing ([JustTCG](https://justtcg.com)):** TCGplayer market prices for every condition and finish. Magic prices the matched printing by Scryfall id; Cyberpunk prices come from one daily batch for the whole game, so scans cost no JustTCG requests. Picking another printing in the dropdown fetches its prices (`/api/price`). Without a `JUSTTCG_API_KEY`, Magic shows Scryfall's Near Mint price and Cyberpunk shows the snapshot's prices.

## 24-hour caching

- **On the device:** each scan is fingerprinted with ORB keypoints (`lib/cardMatcher.ts`) and kept in localStorage for 24 h. Rescanning the same card is answered instantly with no server call. "Rescan (skip cache)" forces a fresh read and replaces the cached entry.
- **On the server:** catalog lookups and prices are cached for 24 h (`lib/catalog/`, `lib/pricing/`). JustTCG's free plan allows 100 requests a day and 1,000 a month, so this keeps repeat scans free. The cache lives in memory; swap in Redis/KV through the `TtlCache` interface in `lib/cache.ts` if you deploy to serverless.

## Setup

```bash
cp .env.local.example .env.local   # add your ANTHROPIC_API_KEY
npm install
npm run dev                        # http://localhost:3000
```

**On a phone:** cameras only work over HTTPS. Run `npm run dev:https` and open `https://<your-lan-ip>:3000` on the phone, accepting the self-signed certificate. Or deploy to Vercel.

## Catalog snapshots

`data/catalog/cyberpunk-tcg.json` is generated by `npx tsx scripts/sync-catalog.ts` (about 32 JustTCG requests at 10/minute, so a few minutes). Re-run it and commit the result when a new set releases.

## Tests

- `npm test`: unit tests (matching, retrieval against the real snapshot, pricing with mocked APIs, stability).
- `npm run test:e2e`: Chrome with a fake camera feed and a mocked identify API (detector, auto-scan, device cache, pricing UI, overlay). Set `PLAYWRIGHT_CHROME_PATH` if Chrome isn't at the default macOS path.

## Config (`.env.local`)

| Variable | Default | |
|---|---|---|
| `ANTHROPIC_API_KEY` | none | required |
| `JUSTTCG_API_KEY` | none | prices by condition; free key at justtcg.com |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | reads the card |
| `ANTHROPIC_CHOOSER_MODEL` | same as `ANTHROPIC_MODEL` | picks among candidates when ambiguous |
| `CACHE_TTL_MS` | `86400000` | server lookup cache TTL |
| `RATE_LIMIT_PER_MINUTE` | `20` | per-IP limit on model calls |
| `NEXT_PUBLIC_OPENCV_URL` | jsDelivr `@techstark/opencv-js@4.10.0-release.1` | self-host to avoid the CDN |
